# AI 유튜브 검색기 (AI YouTube Searcher)

유튜브 실제 UI 디자인을 계승한 **AI 기반 영상 내용 검색 & 타임스탬프 점프 재생 & Q&A 웹 서비스**입니다.

---

## 🌟 주요 기능
1. **유튜브 다크 모드 스타일 UI**: 상단 검색창에 유튜브 영상 링크를 넣으면 즉시 영상이 로드됩니다.
2. **YouTube IFrame API 플레이어**: 외부 음향(볼륨) 조절 슬라이더(0~100%) 및 음소거 토글을 지원합니다.
3. **Gemini 3.5 Transcribe 음성 전사 & CSV 스마트 캐싱**:
   - 오디오를 자동 다운로드하여 고정밀 타임스탬프(`[MM:SS]`)와 화자 분리가 포함된 대본을 추출합니다.
   - **동일한 링크 주소는 `transcripts.csv` 파일에 자동 저장**되며, 재검색 시 오디오 다운로드와 STT 과정을 생략하고 저장된 대본을 즉시 불러옵니다. (시간 절약 & API 비용 0)
4. **영상 내용 검색 & 점프 재생 (In-Video Search)**:
   - 영상 속 특정 키워드를 검색하면 일치하는 대본 구간들이 하이라이트됩니다.
   - 검색 결과를 클릭하면 해당 시간 위치로 영상이 즉시 이동하여 바로 재생(PLAY)됩니다.
5. **Gemini 3.8 Flash 영상 질의응답 (Q&A)**:
   - 영상 대본을 완벽히 숙지한 AI에게 궁금한 점을 질문하면 핵심을 요약해 답변합니다.
   - 답변 내에 언급된 타임스탬프(`[01:23]`)를 클릭하면 해당 장면으로 바로 점프합니다.

---

## 🚀 실행 방법

### 1. 환경 변수 확인
```bash
export GEMINI_API_KEY="your_gemini_api_key"
```

### 2. 서버 실행
```bash
cd ai-youtube-searcher
python3 run.py
```

### 3. 웹 접속
웹 브라우저를 열고 다음 주소로 접속합니다:
👉 **http://localhost:8001**
